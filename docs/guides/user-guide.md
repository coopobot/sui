# 用户指南

本文面向**使用**随手记 Sui 的用户：从安装客户端、连接服务端，到日常记笔记、多端同步与
版本恢复。服务端部署见[部署指南](../deployment.md)，网页剪藏见[网页剪藏](web-clipper.md)。

## 1. 整体概念

随手记 Sui 采用「**本地优先 + 自托管服务端**」架构：

- **本地优先**：所有笔记保存在设备本地（SQLite），不联网也能正常查看、编辑、搜索。
- **自托管**：同步服务端跑在你自己控制的机器上（家里的电脑、NAS 或云服务器），数据完全归你所有。
- **多端**：手机、平板、电脑、浏览器（Web）使用同一套笔记，通过服务端同步保持一致。

关键术语：

| 术语 | 含义 |
|------|------|
| 笔记本 | 笔记的分组容器，可嵌套（如「工作 / 项目A」） |
| 标签 | 跨笔记本的柔性分类，一篇笔记可打多个标签 |
| 收件箱 | 专门收纳网页剪藏产生的笔记，一键剪藏后统一整理（它是按**剪藏来源标记**筛选的**视图**，不是笔记本——整理进笔记本后仍留在收件箱）|
| 剪藏 | 通过浏览器扩展把网页保存为笔记（自动转为 Markdown） |
| 登录与会话 | 用**账号密码**登录后，令牌由客户端自动持有并透明刷新（**无需手工粘贴**） |
| 版本历史 | 一篇笔记的所有历史修订，可随时回滚 |

## 2. 安装客户端

### 2.1 运行 Flutter 客户端

客户端**不预设服务端地址**，地址在应用内的「同步设置」里填写（见 §2.3）。

```bash
cd clients/flutter_app
flutter run -d chrome    # 浏览器（Web，本机已验证可运行）
flutter run -d windows   # Windows 桌面（需在 Windows 宿主构建）
flutter run -d linux     # Linux 桌面（需 clang / ninja-build / pkg-config / libgtk-3-dev）
flutter run -d android   # Android 手机 / 平板（需 Android SDK + 连接设备）
```

六个平台目录（`web` + 桌面/移动五端）均已随仓库提供，无需再执行 `flutter create`；
能否运行只取决于本机是否装了对应工具链。Web 端最省事，适合先跑起来体验。

### 2.2 客户端界面

桌面 / 平板宽屏下为**三栏布局**：

```
┌─────────────┬──────────────┬──────────────────────┐
│ 笔记本树     │ 笔记列表      │ 编辑区（Markdown 三态） │
│ ├ 全部笔记   │ · 笔记 A     │                      │
│ ├ 收件箱     │ · 笔记 B     │  格式 / 源码 / 预览    │
│ ├ 工作       │              │  历史 / 导出 / 删除    │
│ │ └ 项目A    │              │                      │
│ └ 生活       │              │                      │
│ 标签: #xxx   │              │                      │
└─────────────┴──────────────┴──────────────────────┘
```

手机窄屏自动切换为抽屉式导航，点击左上角菜单展开笔记本树。

**桌面端专属（v0.8.0 / M7）：**

- **折叠面板**：顶栏左上角的折叠图标按钮可**分别**收起 / 展开左栏（笔记本树）与中栏（笔记列表），
  折叠后该面板与其分隔线一并消失，得到纯编辑区沉浸写作；折叠状态是**本机视图偏好**，**重启后保持**且不同步。
- **菜单栏**：顶栏「**文件 / 编辑 / 视图 / 同步 / 帮助**」五个菜单（「同步」为 v0.12.0 新增），
  菜单项与顶栏图标按钮、编辑快捷键**同源**——不可用命令**置灰**，有状态命令（如面板显示）显示
  **勾选**，快捷键以右侧提示呈现。「文件 → 退出」会先落库再退出，避免丢失未保存内容；
  「同步 → 全部重新同步」见 §4.5。
- **查看版本号**：菜单「**帮助 → 关于随手记 Sui**」会显示**当前版本号**（反馈问题时请一并提供）；
  窄屏移动端与 Web 端在顶栏「**更多**」菜单里可打开**同一份**「关于」（v0.12.1 / FR-56）。
- **编辑三态**：编辑区提供「格式 / 源码 / 预览」三态切换，编辑模式同样**重启后保持**。
- **设置中心（v0.14.0 / M14）**：顶栏**设置图标**、菜单「**文件 → 设置…**」或快捷键
  `Ctrl / Cmd + ,` 打开**统一设置**——**外观**（主题 / 字体）、**同步与账号**、**本地存储**（仅桌面）、
  **附件缓存**、**关于**；顶栏同步状态图标点按会**直接停在「同步与账号」**。窄屏移动端与 Web 端在顶栏
  「**更多**」菜单里同样有「设置」。

以上折叠开关与菜单栏仅在桌面端（Windows / macOS / Linux）渲染，窄屏移动端与 Web 不显示，行为不回归。

**桌面端专属（v0.9.0 / M8）：独立笔记窗口**

- **在独立窗口打开**：选中一篇笔记后，从菜单「**文件 → 在独立窗口打开**」或笔记列表项的**右键菜单**
  选择「在独立窗口打开」，该笔记会在一个**独立 OS 窗口**中打开。主窗口**照常保留**这篇笔记的编辑面，
  两处指向**同一条**笔记、共享同一份 Markdown 正本，两边编辑**实时互相同步**，不会各写各的。
- **一笔记一窗口**：同一篇笔记只会有一个独立窗口，列表项上会标出「独立窗口」标识；再次打开同一篇笔记
  只是**聚焦**已开的窗口（若已最小化会先**还原**），不会重复弹窗。
- **窗口各记各的编辑模式**：每个窗口的「格式 / 源码 / 预览」模式**互相独立**、各自记住并在**重启后
  保持**；而当前选中的笔记本、搜索关键字、标签筛选等仍为**全局**，独立窗口不会打乱主窗口的浏览位置。
- **关闭与退出**：关闭某个独立窗口即释放它；当**所有窗口**（含主窗口）都关闭时会**退出应用**；菜单
  「**文件 → 退出应用**」会先落库、再尽力推送后关闭全部窗口退出，避免丢内容。

> 独立窗口仅在桌面端（Windows / macOS / Linux）可用；移动端与 Web 不显示该入口，行为不回归。

### 2.3 连接服务端（首次配置）

客户端开箱即用（纯本地也能写），要同步才需要连服务端。点顶栏的**云图标 /「同步设置」**
打开对话框：

| 区域 | 内容 |
|------|------|
| 状态行 | 未连接 / 已连接 / 同步中… / 同步失败（附原因） |
| 服务端地址 | 如 `http://127.0.0.1:8080`（局域网用机器 IP，公网用你的域名） |
| 用户名 / 密码 | 配「注册并连接」（新建账号）或「登录并连接」（已有账号） |
| 测试连接 | 只探活，不保存 —— 先确认地址通不通 |
| 会话操作 | 未连接时用「注册并连接」（首启建号）/「登录并连接」（已有账号）；已连接时显示「断开连接」。**v0.12.2 起不再有 Token 输入** |
| 本地存储 | **仅桌面端**：当前数据目录与占用、「更改位置…」、「打开所在文件夹」（见 §3.11） |
| 本机设备 ID | 自动生成、随配置持久化，用于标识修订来源设备 |
| 附件缓存 | 当前占用 / 上限，可改上限（单位 MB，默认 512） |

配置会存入本机数据库，**重启后仍在**，之后编辑自动防抖推送。若地址为空或**未建立登录会话**，
状态会停在「未连接」（v0.12.2 起判据由「Token 为空」改为「无有效会话」）。

## 3. 日常使用

### 3.1 新建笔记

1. 点击笔记本树右上角「＋」→ 选择笔记本（或留空放「全部笔记」）。
2. 输入标题与正文，正文使用 Markdown 语法。
3. 内容自动保存（无需手动点保存）。

### 3.2 Markdown 三态编辑

Markdown 是笔记的**唯一正本**，编辑区提供「格式 / 源码 / 预览」三态切换（窄屏下三态以图标呈现）：

- **格式**：所见即所得的格式化编辑，改动**即时回写** Markdown。**Markdown 记号本身不可见**——
  `**加粗**` 只显示加粗文字、`## 标题` 只显示放大标题、`- 项` 显示为「• 项」、任务项显示为勾选框、
  `> 引用` 显示为左侧竖条、`---` 显示为水平线、链接只显示文字；**未识别**的记号（如落单的 `**`）仍原样显示。
- **源码**：直接编辑原始 Markdown 文本（记号可见、可逐字符改）。
- **预览**：查看渲染后的最终效果。
- 支持：标题 `#`、列表（无序 / 有序自动编号）、链接、图片、粗斜体、删除线、高亮、引用、代码块、表格、任务列表、附件胶囊等常见语法。
- **格式单元是「整体」**：光标不会停在记号内部（自动跨过）；退格 / 删除落在记号上时**一次取消整处格式**
  而内容保留（`**粗**` → `粗`、`## 标题` → `标题`），空勾选框行按退格即退出列表；**表格行永不与相邻
  文字合并**——删除紧贴表格的勾选框时表格逐字不动、仍以表格呈现。
- **缩进只产出合法结构**：孤立勾选框行最多缩进到 3 个空格（再缩进不变），有父列表项时缩进为嵌套；
  不会再出现「右缩进后预览显示成字面量 `[ ]`（缩进代码块）」。

**格式工具栏**（格式模式下可用）按使用频度从左到右排列：加粗 / 勾选框 / 撤销 / 重做 / 斜体 / 删除线 / 高亮 / 列表 / 缩进 / 引用 / 代码块 / **表格** / 链接 / **插入图片** / **附件** / 分割线 / **简化格式** / 标题一~三。
**把鼠标停在按钮上即可看到它对应的快捷键**（如「加粗 (Ctrl+B)」「表格 (Ctrl+Shift+T)」）；没有快捷键的按钮（插入图片 / 附件）只显示名称。
常用操作均有快捷键（Ctrl+B 加粗、Ctrl+K 链接、Ctrl+V 富粘贴、Ctrl+Shift+V 纯粘贴、Ctrl+Shift+T 插入表格等）。

**插入超链接**：选中要作为链接的文字（可留空）→ 点工具栏「链接」或按 `Ctrl+K` → 在弹框里填「显示文字」与「网址」→「插入」。
网址**不写协议会自动补 `https://`**（`mailto:`、`#锚点`、`/相对路径` 等写法保持原样）；网址留空时「插入」不可用，不会改动笔记。
**表格单元格里也能插链接**：单元格上下文栏有「链接」按钮；若光标正在某个单元格里，直接点工具栏「链接」也会写进**那个单元格**（以软换行追加，其余单元格不动）。

### 3.3 管理笔记本与标签

- **新建笔记本**：笔记本树底部「＋ 新建笔记本」。
- **嵌套**：在笔记本上右键 / 长按 → 新建子笔记本。
- **标签**：编辑器中输入标签回车即可添加，点标签可在全局过滤。

### 3.4 搜索

顶部搜索框输入关键字，即时匹配**标题与正文**，全局范围（也可先选中某个笔记本再搜索）。

> 当前为 `LIKE` 子串匹配，FTS5 全文搜索仅架构预留、未启用。

### 3.5 置顶 / 归档 / 删除

- **置顶**：列表项右上角图钉，置顶笔记排在最前。
- **删除**：编辑器右上角垃圾桶；删除为软删除（墓碑），多端同步后保持一致。

### 3.6 附件

**添加**：打开笔记 → 格式工具栏的**回形针图标**（「附件」）→ 弹出**附件面板** → 点「添加附件」
选择文件（可多选）。附件会挂到这篇笔记上，并在正文中**以独占段落**自动插入一行引用——
**图片**插 `![文件名](sui://<sha256>)`（块级内容，其下方文字整体下移、光标可正常越过，
格式 / 预览模式下直接渲染）；**PDF / 文本 / 压缩包等其它类型**插
`[文件名](sui://<sha256>)`，在格式 / 预览模式下呈现为**附件卡片**（不再显示成加载失败的图片）。

**多选与进度**：选完文件后，附件面板会**立即列出本批次待添加的文件**（带「添加中…」），
每完成一个就换成正常卡片；批次进行中「添加附件」显示「正在添加…」并置灰——
**连点不会重复添加**，正文引用与附件列表始终一一对应。

**大文件**：添加附件只做本地入库与正文写入，**不等网络上传**；字节由同步周期在后台补传，
因此 20 MB 级文件在慢网下也不会卡住编辑。上传完成前卡片显示「待上传」。

**查看**：点格式工具栏的「附件」按钮打开**附件面板**，面板内列出该笔记的全部附件，点击卡片即可
打开（本机没有字节时会自动从服务端下载并缓存）。

**移除**：卡片右侧的 ✕。移除只是解除这篇笔记的引用，不会影响其他笔记对同一附件的引用。

每张卡片会标出该附件当前的可用性：

| 状态 | 含义 |
|------|------|
| 已同步 | 本机有字节，服务端也确认持有 —— 换任何设备都能打开 |
| 待上传 | 本机有字节，但还没传到服务端（如刚添加时断网）。联网后自动补传 |
| 仅本机 | 本机有字节，但当前未连接服务端。只有这台设备能打开 |
| 未下载 | 本机没有字节，点击卡片时按需下载 |

**关于存储占用**：附件字节**不会全部下载到每台设备**，只有你真正打开过的才会缓存到本地，
且总量受「缓存上限」约束（默认 512MB，可在同步设置里调整）。超出上限时，最久没打开、
且没有被任何笔记引用的附件会被自动清理，再次打开会重新下载。

> 因此同一附件在多篇笔记中被引用时，本地只会存一份（按内容去重）。

**预览与外部编辑回写**：

- 在附件面板点击附件卡片，弹出**预览弹窗**——文本文件可直接阅读（长文截断）、图片可缩放查看、PDF 与其他类型显示文件元信息。
- 预览弹窗中「用系统默认应用打开」会调用本机默认程序打开附件。**外部编辑保存后，Sui 会自动检测文件变更并回写**：生成新的 sha256 → 更新正文里的 `sui://` 引用 → 上传同步到服务端，换台设备打开即可看到最新版本。

### 3.7 表格编辑

格式模式下，点格式工具栏的**表格图标**（或按快捷键 Ctrl+Shift+T），弹出「插入表格」对话框：

- 输入行 / 列数（默认 3×3，上限 20×20），点「插入」即可在光标处插入一张 GFM 管道表。
- 表格呈现为**独占块**，直接点击单元格即可编辑内容，按 Tab 键跳到下一个单元格。
- 鼠标悬停在表格上时，行 / 列头部会出现「+」「−」按钮，可就地增删行列。
- 源码模式下可直接编辑原始 Markdown 表格文本，格式模式与预览模式会同步渲染。

> 表格以 GFM 管道表（`| 列1 | 列2 |` + `| --- | --- |`）形式存入 Markdown 正本，
> 与任何支持标准 Markdown 表格的工具完全兼容。

### 3.8 粘贴与简化格式

**粘贴保留格式（Ctrl+V）**：从网页 / Word / 其他富文本应用复制内容后，在 Sui 格式模式下直接 Ctrl+V 粘贴，
会自动将 HTML 富文本转换为 Markdown（保留表格、列表、引用、粗斜体、链接、代码块等结构）。
无法识别的格式会降级为纯文本，**绝不丢字**。
> **`v0.14.1` 起**改为由**自研原生通道**真正读取剪贴板的 **HTML 表示**（此前 Windows / Android 读到的一直是
> 纯文本），并在 Markdown 无法表达时保留**颜色 / 背景色 / 字号**为受限样式；详见 [§3.16](#316-粘贴保留格式的边界v0141--fr-71)。

**纯文本粘贴（Ctrl+Shift+V）**：只粘贴纯文本，且会自动转义 Markdown 特殊字符
（`*` `_` `` ` `` `#` `[` `]` `(` `)` 等），避免意外触发格式渲染。

**简化格式**：选中一段文字后，点工具栏的「简化格式」按钮（或按 Ctrl+Space），
会**剥离全部行内格式**（加粗、斜体、删除线、高亮、行内代码），但**保留块级结构**
（列表、引用、代码块、表格）。可用于清理从别处复制来的杂乱样式，快速统一为纯文本内容。

### 3.9 有序列表自动编号

在 Markdown 正本里，有序列表统一写 `1.`（「懒编号」风格）——格式模式与预览模式会**自动按 DOM 顺序
渲染为 1. / 2. / 3.** 的连续编号。这样做的好处：

- **增删条目不用手动改编号**：在中间插入或删除一行，后续编号自动重排。
- **空行隔断编号重启**：两个有序列表之间隔了空行或其他内容，编号会从 1 重新开始。
- **源码模式不受影响**：你仍然可以在源码模式里手动写 `1.` `2.` `3.`，格式模式同样能正确渲染。

快捷键：Ctrl+Shift+O 切换有序列表。

### 3.10 加密笔记本（锁定密码保护）

把某个笔记本设为**加密笔记本**后，其中笔记的**标题与正文在本机加密后才落库、才上传**——
服务端全程只见密文、**无法解密**（这也是「服务端搜不到加密笔记本内容」的原因）。

- **设置**：对笔记本启用加密 → 设置**锁定密码**（独立于登录密码，只在本机校验，**不会上传**）。
- **解锁**：打开加密笔记本内的笔记时要求输入锁定密码；解锁后查看与编辑体验与普通笔记一致。
- **回锁**：顶栏「立即锁定」手动回锁；**15 分钟无操作**也会自动回锁（之后需重新输入密码）。
- **未解锁时**：列表显示「🔒 加密笔记」占位，**不进编辑、不纳入搜索**；笔记本树上有锁标记。
- **跨端**：密钥**不随同步**——在另一台设备上首次查看同样要输入锁定密码（各端各自解锁）。
- **多端同步**：加密笔记照常参与同步与冲突合并；**未解锁的设备不会就地合并**（保持排队，
  由已解锁的一端完成合并），**绝不丢字**。

> ⚠️ **锁定密码无法找回**：服务端没有它，也没有任何后门。忘记密码意味着该笔记本内的内容
> **永久不可读**——请在设置后立即妥善保存（例如写进密码管理器）。

### 3.11 本地存储位置（桌面端，v0.12.2 / FR-58）

「同步设置 → 本地存储」显示**当前数据目录**与**占用**（库 / 附件），并可：

- **打开所在文件夹**：在系统文件管理器里定位数据目录；
- **更改位置…**：把本地库与附件缓存迁移到其它目录（例如大容量数据盘）。

迁移流程：选目录 → 前置校验（同路径 / 已含数据会被拒；非空目录需确认）→ 确认（列明将迁移的
内容与占用）→ 进度（落盘 → 复制库 → 复制附件 → 校验 → 切换）→ 完成后提示**重启生效**。

要点：

- **旧数据会保留**在旧目录，确认新位置一切正常后再手动删除；
- 迁移失败时**仍使用旧位置**（指针不切换），界面给出失败原因与重试入口；
- 迁移**不改变**服务端数据、登录会话与同步状态，**不会**触发换库流程；
- 若数据目录放在外置盘 / 网络盘，未挂载时启动会**整屏阻断**并让你三选一
  （重试 / 改回默认目录 / 重新指定路径）——**不会**静默换目录，也不会删你的数据。

### 3.12 批量导入本地文件（M13 / FR-60\~FR-62）

把**本机既有的笔记文件**批量搬进 Sui——支持 `.md` / `.markdown` / `.txt` / `.html` / `.htm`，
典型场景是**从印象笔记导出为 HTML** 后整体导入。

**入口**（三端同源同效）：

- 桌面端：菜单「**文件 → 导入文件…**」（加速键 `Ctrl+Shift+I`）；
- 移动端 / Web：顶栏「**更多 → 导入文件…**」。

**步骤**：

1. 先在左栏**选中目标笔记本**（不选则导入到「未分组」）；
2. 打开「导入文件…」→ 对话框显示「导入到：<笔记本>」（**只读**，导入期间改选左栏**不会**改变落点）；
3. 点「**选择文件…**」多选文件，或（桌面 / 移动端）点「**选择文件夹…**」递归导入整个导出目录；
4. 导入过程显示「已处理 n / 共 m」，可**取消**——已导入的笔记保留，重选同一批即可续跑；
5. 结束后弹出**导入报告**：`成功 / 跳过 / 失败 / 未本地化资源` 四类计数 + 逐项明细，
   可「复制报告」用于反馈（报告**不含笔记正文**）。

**导入后会发生什么**：

- 正文统一变成 **Markdown**：`.md` **逐字节保真**（不改空白、不转义）、`.txt` 只做**空白规整**、
  `.html` 做**语义等价**转换（标题层级 / 列表 / 引用 / 代码块 / GFM 表格 / 粗斜体删除线 / 链接 /
  图片 / 水平线 / 软换行）；
- HTML 里的**本地图片与附件**解码入库为内容寻址附件（正文改 `sui://<sha256>`）——
  **原导出目录删掉也能正常显示**；
- 导入的笔记就是普通笔记：可编辑、可搜索、可随多端同步；导入**不会打断**你正在编辑的笔记，
  也**不需要联网**（转换全在客户端），联网后自动上行；
- **重复导入不会翻倍**：按「标题 + 正文」的内容指纹在**本机**记账，同一内容只导入一次
  （报告中计为「跳过 · 重复」）。

**对印象笔记导出的适配**：正文容器 `<en-note>`、逐行 `<div class="para">` 段落、
标题（`<h1 class="noteTitle">` / `meta[itemprop=title]`，**只取一次**避免双标题）、
`li` 里的**复选框 → 任务列表**（`- [ ]` / `- [x]`）都能正确还原；「**单个网页**」导出的一份
HTML 里若含多篇笔记（`div.html-note` 分节）会**拆成多篇**；导出目录里的**索引页**
（如 `Evernote_index.html`）会被自动跳过。

**已知限制**（都不影响其它笔记）：

| 情形 | 表现 |
| --- | --- |
| 印象笔记里的**非图片附件**（PDF / 压缩包等） | 官方 HTML 导出**不给出可用链接**（正文只有「Untitled Attachment」字样）→ 保留该文字并计入「未本地化资源」，**不会**猜着配文件 |
| 资源目录缺失 / **Web 端**导入 HTML | 该图片保留 alt 文本并计入「未本地化资源」 |
| HTML 里的**远端图片**（`http(s)://`） | 保持原 URL、导入**不出网**；原地址失效则图片不可见 |
| **GBK / GB18030** 编码的 `.txt` | 不支持（按 UTF-8 解码并以替换字符降级，可能乱码；报告会标注「编码可能不正确」） |
| 同一文件在**别的设备**上再导入一次 | 去重只记在**本机**，会再产生一份（可手动删除） |
| 笔记原本的**创建 / 修改时间与标签** | 本轮不写入（元数据只用于取标题），导入时刻即创建时间 |
| 单文件 > 20 MB、单批 > 500 个文件 | 超限项跳过并计入报告，其余照常导入 |

**`v0.13.1` 修正（2026-10-12）**：修掉了「导入后正文挤成一行、或正文里出现 `<br>`」的问题——旧版
印象笔记「导出为网页」（`exporter-version: YXBJ`）的正文结构（`<a name="…"/>` 不闭合 + `<span>`
里嵌 `<div>`）过去被当成**一个段落**，段界只能退化成行内 `<br>`；现在能正确还原段落 / 标题 / 列表，
且**段落内的换行写成真换行**（只有**表格单元格**里仍写 `<br>`——GFM 管道表不支持多行单元格，
格式模式会把它渲染为换行）。同时：按文件夹导入时**不再把导出资源目录**（`<笔记标题>_files`）里的
旁挂文件（如 `org.txt`）当成笔记；**删除后重新导入**不再被指纹挡住。

> **已导入过的笔记需重新导入一次**才能拿到新结构：删除这批笔记（进回收站即可）→ 选中目标笔记本 →
> 「文件 → 导入文件…」→「选择文件夹…」重新选导出目录（删除不影响重新导入）。

**`v0.13.4` 修正（2026-10-13）**：修掉「导入后附件显示错乱」——「链接包图片」
（`<a href="文件"><img src="缩略图"></a>`，印象笔记导出里很常见）过去被组合成**嵌套引用**，而客户端只认
**扁平**的 `sui://` 引用，于是正文里会露出 `](sui://…)` 残余、附件名前面多一个 `!`。修复后正本是单条
附件引用 `[文件名](sui://…)`（点击即可打开；图片仍是 `![](sui://…)`），装饰性缩略图不再单独挂成附件。

> **同样需要重新导入一次**才能拿到新正本：删除这批笔记 → 选中目标笔记本 →
> 「文件 → 导入文件…」→「选择文件夹…」重新选导出目录。

**`v0.13.5` 修正（2026-10-13）**：修掉「列表前面出现反斜杠」（如 `1\. LiblibAI…`）——真正的
`<ol>` / `<ul>` 现在一律渲染为**真列表**，来源里手写的编号段落也按编号项呈现，**不再出现 `\.`**
（格式模式不会渲染转义，所以任何进入正文的转义都会露出来，本次直接把该转义口径去掉）。
同一补丁还修掉一个**内容丢失**：剪藏常见的 `<ol><li>a</li><ul>…</ul></ol>` 非法嵌套里，作为兄弟的
子列表此前被整段丢弃（某些笔记只剩三成内容），现在会归入前一个列表项。

> **同样需要重新导入一次**才能拿到新正本。

### 3.14 分割线：标准 Markdown 正本 + 紧贴渲染（v0.14.1 / v0.14.3 / FR-72）

格式模式下点工具栏「分割线」（或按 `Ctrl / Cmd + Shift + -`），`---` 会作为**独立的一块**插到
**光标所在行的下一行**并**独占一行**：**上方保证一个空行**（不会被解析成上一行的 setext 下划线）、
**下方不补空行**（紧随原有正文）。插入后的**正本**即：

```
段落1

---
段落2        ← 光标停在这一行行首，直接打字即可
```

- **正本是标准 CommonMark**：`---` 上方一个空行即成立（与 Gitea / GitHub / Typora 语义一致）。空文档 → `---\n`；
  文末无行尾换行 → `末行\n\n---\n`；光标停在空行上 → `正文\n\n---\n后续`（**复用既有空行，不堆叠**）。
- **两态都紧贴、都不多出空行**：格式模式把「上方空行换行 + `---` 行 + 该行自身的行尾换行」（规则记号区间
  `[4,9)`）折叠成一个**紧贴**的规则呈现单元，预览态就是标准 `<hr>`——**两种正本形态都只占 3 个视觉行**，
  不出现「段落1 / 空行 / 分割线 / 空行 / 段落2」的多余行。
- **线色线宽同源**：格式模式的规则呈现单元是 **1px `outlineVariant`** 细线、**居中**、无外边距、按可用段宽铺满；
  预览态是 **1px `outlineVariant` 上边框**的 `<hr>`（同色、同 1px）。正本里的这一行**恒为 `---` 三个字符**——
  渲染**不改动正本**，标记区间与正本**等长**，三态往返**逐字节不变**。
- **间距现状：两态目前不一致（已知待决项）**：真机格式态「段落1 → 段落2」顶距 **54.75px**，预览态 **37.02px**
  （`p` 14 × 1.43 + `blockSpacing` 8 + `<hr>` 1px + 8）——格式态比预览**松 17.73px**。**压小呈现单元无效**：
  该行行盒由正文 `StrutStyle` 的 **24px 下限**（为图片行而设）与占位对齐决定，与呈现单元高度无关（高度取
  17 / 20 顶距同值）；曾试的「规则行以显式换行结束」在真机**更差**（4 行 / 78.75px）**已撤回**。要一致需改正文
  strut（**空行行高会随之变小**）或调大预览间距（与「紧贴」相反）——**需产品决策**，当前**登记为待决项**，
  不是回归、不是缺陷。
- **再点一次 = 移除（幂等切换）**：光标停在**分割线行**上，**或停在紧贴它下方那一行的行首**，再点「分割线」
  （或再按快捷键）就**移除**这一行——可反复往返，不会越点越多。
- **删除分割线绝不吞正文**：退格 / 删除命中分割线时是**整行移除**——只删 `---` 这一行（含它自己的行尾换行）
  外加紧邻其下的一个换行，**上方空行保留**、正文**一字不动**。例如 `段落1\n\n---\n段落2` 把光标放在「段落2」
  行首按一次退格，得到 `段落1\n\n段落2`。
- **`文字` 换行后紧跟 `---`（无空行）是标题，不是分割线**：这是 Markdown 的标准「二级标题」写法（setext），
  两态判定一致。要分割线，请让 `---` **上方留一个空行**；要二级标题，直接用 `## 标题` 更明确。
- **表格 / 代码块里点也不会打坏结构**：光标在表格或围栏代码块内时，锚点**外移到整块之后**，
  表格与围栏代码块**逐字不动**、`---` 也不会跑进代码块内容里。

> **小提示**：正本字节恒为 `---`，**格式 / 源码 / 预览三态往返逐字节不变**；格式模式看到的「紧贴」全部来自
> **渲染层折叠**，不改动笔记内容。
> 与 `v0.14.2` 的区别：`v0.14.2` 曾把「`文字` 换行后紧跟 `---`」也判成分割线（偏离标准，已撤回）；
> 现在它是**标准的 setext 二级标题**，与 GitHub / Gitee / VS Code 行为一致。

### 3.15 链接可以点开（v0.14.1 / FR-70）

**预览模式**：笔记里的 `[文字](https://…)` 与**裸网址**（直接写的 `https://…`）都是**可点链接**，
点按即用**系统默认浏览器**打开（不在应用内打开、不内嵌网页）。

**格式模式**：光标落在链接里时，链接下方会出现一条**链接条**——左边是网址，右边两个按钮：

| 按钮 | 作用 |
| --- | --- |
| **打开** | 用系统默认浏览器打开该地址（与预览态同一路径） |
| **编辑** | 打开链接弹框，改「显示文字 / 网址」 |

- 链接在格式模式下是**一个整体**：**单击选中、双击打开**（与附件卡片一致）。
- **表格单元格里的链接同样能打开**（光标落在单元格内的链接里即出链接条），表格不会因此打回原形。
- **安全口径**：只打开 `http` / `https`（`mailto:` / `tel:` 交给系统），
  `javascript:` / `data:` / `file:` 等**一律不打开**并给出提示，**笔记内容一字不改**。
- 打开失败（地址无法解析、没有可用浏览器）会给出提示，**不会**让编辑器失焦或丢内容。

### 3.16 粘贴保留格式的边界（v0.14.1 / FR-71）

**普通粘贴 `Ctrl / Cmd + V`**：优先读取剪贴板里的 **HTML 表示**并转成 Markdown——
标题、有序 / 无序列表（**含嵌套**）、表格、引用、代码块、**加粗 / 斜体 / 删除线 / 行内代码**、
链接、图片、任务项都会保留；**Markdown 没有对应写法的样式**（文字**颜色**、**背景色**、**字号**）
会保留成受限样式，**格式模式与预览模式显示同一种颜色**。

**纯文本粘贴 `Ctrl / Cmd + Shift + V`**：恒为纯文本（并转义 Markdown 特殊字符），用于「只要文字」的场景。

**图片**：剪贴板里的**内联图片**（`data:` 形式）会存进附件库并以 `sui://…` 引用；
**指向网页的远端图片**保留原网址（**粘贴过程不会去下载**）。

**失败与限额**：读不到富文本、HTML 为空或转换出错时，**静默回落为纯文本粘贴**——
不会「按了没反应」，也不会「只粘进半截」；超大剪贴板内容（默认 **4 MiB** 文本上限、
单张内联图片 **8 MiB**）超出部分按降级处理。任何粘贴都是**一次可撤销**的编辑。

> **平台边界（重要）**：剪贴板的 HTML 表示目前**只在 Windows 与 Android 上支持**
> （Windows 读系统的 HTML 剪贴板格式、Android 读 `ClipData` 的 HTML 项）。
> **macOS / Linux / Web 本轮未实现**——在这些平台上 `Ctrl+V` 会**回落为纯文本粘贴**（内容完整、但没有格式），
> 这属于**已知限制**而非故障。真要带格式，可在 Windows / Android 上粘贴后再同步到其它端。

### 3.17 快照正文里的 HTML 块与整页截图（v0.14.1 / FR-69）

用**全页快照**模式剪藏的长页面，正文里可能出现少量形如
`<div style="text-align:center">…</div>` 的**内嵌 HTML 块**——它们是**原网页的版式信息**
（居中、颜色、背景、缩进等 Markdown 表达不了的东西），被刻意保留在**正文里**：

- 这些块是**正本的一部分**（就是普通字符），**不是**隐藏数据、也不是「富文本中间态」：
  源码模式下**逐字可见、可复制、可直接编辑**，把它整段删掉就回到纯 Markdown 的观感。
- **预览模式**：块按受限样式渲染，和 Markdown 段落**按原文顺序**混排；
  块里的图片走本地附件（指向外网的图片**只占位、不会联网取图**），链接与正文链接一样可点。
- **格式模式**：这些块是**一个整体**（原子块）——不会露出 `<div …>` 标签原文、光标不会跑到块内字符之间，
  单击选中**整块**，在块后按退格 / 删除键**一次整块删除**（一次撤销即可恢复）。
- **整页截图**：正文**末尾**的 `![整页截图](sui://<sha256>)` 是剪藏时保存的**整页位图**
  （滚动拼接、含视口之外的内容），用于原页改版 / 下线后**像素级**回看。
  如果该次采集失败（没有站点授权、页面不允许截图、超时或体积超限），**只是没有这张图**，
  剪藏与笔记本身照常可用。
- **网页原件（v0.16.0）**：`snapshot` 模式现在还会保存一份**单文件 HTML 原件**（`webclip` 附件），
  并在正文头部插入 `[网页原件](sui://webclip/<sha256>)`；预览态直接**内嵌网页**（原布局 / 颜色 / 对齐），
  格式态是原子卡片（双击全屏）。有原件时**截图不再追加到正文**，但仍作为附件保留，供 WebView
  不可用时降级。详见 §3.24。
- **老笔记不受影响**：`v0.14.1` 之前的纯 Markdown 快照笔记渲染结果**完全不变**（不会自动改写历史数据）。

### 3.18 笔记内查找与替换（v0.15.0 / M15 / FR-73）

**格式模式**与**源码模式**下按 `Ctrl / Cmd + F`（桌面也可走「**编辑 → 在笔记内查找**」）打开**查找栏**
（`sui-find-*` 一组控件）：

| 控件 / 操作 | 作用 |
| --- | --- |
| 查找输入框 | 输入即**即时高亮**命中项，并显示 `n/m` 计数 |
| 上一个 / 下一个 | 在命中项之间**循环**移动，正文同步滚动 |
| 区分大小写 | 打开后 `A` 与 `a` 视为**不同** |
| 替换输入框 + 单个替换 | 只替换**当前命中**这一处 |
| 全部替换 | 一次替换**全部命中** |
| `Esc` | 关闭查找栏并把**焦点还给正文** |

- **不做正则、不跨行**：关键字按**字面文本**处理，正则元字符（如 `.` `*` `(`）就是普通字符；
  命中范围**不跨越换行**。
- **格式模式会跳过「结构区」**：**表格块 / 快照 HTML 块 / 附件引用 / 链接的 URL 段 / 围栏行**不参与
  查找与替换，查找栏会显示「**已跳过 N 处结构区**」——这样「全部替换」不会把表格结构或
  `sui://` 附件引用改坏。
- **源码模式全量参与**：源码模式看到的**就是正本本身**，所有字符都在查找与替换范围内
  （含表格、HTML 块、链接 URL、围栏行）。
- **替换是一步可撤销**：一次「单个替换」或一次「全部替换」都记为**一步**编辑，`Ctrl / Cmd + Z`
  一次即可整体回退。
- **预览态不提供**：预览模式下按 `Ctrl / Cmd + F` 走的是**中栏「查找笔记」**（跨笔记搜索），
  不是笔记内查找——要改字请切到**格式**或**源码**模式。

> **已知限制**：**不做正则、不跨行**；格式模式命中**结构区**时**跳过**并提示「已跳过 N 处结构区」，
> 要连结构区一起改，请切到**源码模式**。

编辑页右上角的「**属性**」图标打开**笔记属性信息**：

| 呈现方式 | 适用场景 |
| --- | --- |
| **右侧 320px 面板** | 桌面**宽屏**；与「版本历史」**互斥**（开一个会收起另一个） |
| **整页推入** | 窄屏 / 移动端 / Web |
| **右栏** | 独立笔记窗口 |

面板字段：标题 / 所属笔记本（**名称 + 祖先路径**）/ 创建时间 / 上次修改时间 / **来源链接**

- **加密笔记本未解锁不显示字数**：此时正文不在内存里，无法统计。

> **已知限制**：面板**只读**；「**来源链接**」只有**剪藏产生**的笔记才有，手工新建的笔记这一行
> **整行不渲染**；**加密笔记本未解锁**时**不显示字数**。

### 3.20 插入关联笔记与跳转（v0.15.0 / M15 / FR-75）

工具栏「**关联笔记**」（紧随「**链接**」；桌面也可走「**编辑 → 插入关联笔记**」`Ctrl + Shift + L`）
会打开**笔记选择器**：可**搜索**，并自动**排除当前笔记**、**回收站**与**未解锁的加密笔记本**。
选定后在光标处插入一条**标准 Markdown 链接**：

```
[被选笔记的标题](sui://note/<id>)
```

- **三态都能点击跳转**：格式模式（单击选中链接单元、**双击**跳转）、预览模式（点按）、
  源码模式（点按）都可跳转。
- **跳转落点（v0.16.0 起）**：主窗口**先切到目标所属的笔记本 / 收件箱 / 归档视图**，再选中目标笔记，
  并自动清除会遮住目标的搜索词与标签筛选；桌面 / 移动 / Web 一致。
- **目标不可达时给提示、不改正本**：目标已被删除，或目标在**未解锁的加密笔记本**里时，给出提示，
  **笔记内容一字不改**。
- **正本仍是标准 Markdown**：`sui://note/<id>` 是一种自定义协议链接，其它 Markdown 工具会把它当
  普通链接显示（**文字可读、链接不可用**），正本**依然合法**。

> **已知限制（重要）**：链接的**显示文字是写入时的标题快照**——目标笔记之后**重命名**，
> 这条链接的文字**不会自动跟随**（产品**不会**在后台改写你的正本）。要更新文字，请手动编辑该链接，
> 或删掉重新插入一次。

### 3.21 格式模式里键入语法字符会发生什么（v0.15.0 / M15 / FR-78）

格式模式下，凡是**会改变语法树**的 ASCII 标点，键入时会**自动转义后落进正本**——例如你打一个 `*`，
正本里存的是 `\*`；而你在屏幕上**看到的仍然是 `*` 本身**（那个反斜杠**不可见**）。

| 位置 | 敏感的字符 |
| --- | --- |
| **行内**（任何位置） | `` ` `` `*` `_` `~` `=` `[` `]` `<` `&`、**竖线** |
| **行首** | `#` `-` `+` `>`，以及「数字 + `.`」里的那个 `.` |
| **一律不转义** | **围栏代码块内**与**行内代码内**（反引号包起来的片段）原样输入 |

- **只在「合法目标」上转义**：**字母、数字、空格绝不会**被加上反斜杠——转义只发生在真正会给
  解析器带来歧义的位置。
- **IME 组合期不拦**：中文输入法**组字过程中**不会插入反斜杠，**上屏之后**才判定。
- **`\x` 作为整体删除**：删除键打在转义序列上时，`\` 与它后面的字符**一起删掉**，
  不会留下一个孤零零的反斜杠。
- **源码模式一律原样输入**：切到源码模式后，你敲什么就存什么（**没有**自动转义），
  适合精确核对正本、手写 Markdown。

**怎么生成真正的结构（重要）**：因为上面的转义口径，格式模式下**手打** `**x**` / `~~x~~` / `==x==`
会落成正本里的**转义字面量**（语法**不生效**，看上去就是普通字符带着星号）。要生成
**加粗 / 删除线 / 高亮**等结构，请：

1. 用**工具栏按钮**或快捷键（**选中文字**后点「加粗」等）；或
2. 切到**源码模式**手写 Markdown，再切回格式模式查看。

> **已知限制**：格式模式下**手打** `**x**` / `~~x~~` / `==x==` 会落成**转义字面量**（语法不生效）
> ——这是上面「自动转义」口径的**必然结果**，不是故障。要结构请用**工具栏**或**源码模式**。

### 3.22 代码块的编辑与整体删除（v0.15.0 / M15 / FR-81）

格式模式下，**围栏代码块**（用**三个反引号**起止的块）是一个**有底色带的原子块**：

- **块级底色带**：整块有一层**满行宽**的底色（与**预览态**代码块**同色源**），块内的**空行**与
  **两条围栏行**都在底色带**之内**（圆角 + 内边距）。
- **块内照常编辑**：光标可以进到**代码行**里正常打字、删除、粘贴。
- **边界不可破（整块删除）**：光标在**代码首行行首**按 Backspace、或在**末行行尾**按 Delete，
  **不再**能吞掉代码内容或吃掉闭合围栏——改为**整块删除**（连同**两条围栏行**一起删掉），
  **一次撤销**即可恢复，也**不会留下多余空行**。
- **光标不停在围栏行上**：上下移动光标会**跳过**围栏行与块边界的换行，不会「卡」在围栏行上。
- **正本字节不变**：底色带**只影响渲染**，正本里的反引号与代码字符**一个字节都不动**。

> **已知限制**：代码块的**块级底色带**在正文**可用宽度未知**（`paragraphWidth == 0`，例如刚开始
> 布局的那一帧）时**不建立**，此时回退为**逐字形底色**（观感相近，但底色按**字宽**而非满行宽）。

### 3.23 独立窗口专注写作（v0.15.0 / M15 / FR-82）

桌面端把笔记开到**独立窗口**后，独立窗口**不再渲染**顶部的「**标题 + 同步 + 设置**」那一行——
**编辑区整体上移**，把纵向空间全部让给正文，适合**专注写作**。

| 能力 | 独立窗口 | 主窗口 |
| --- | --- | --- |
| 笔记**标题**编辑 | ✅ 编辑器**顶部标题框** | ✅ |
| 窗口拖拽 / 最小化 / 最大化 / 关闭 | ✅ 由 **OS 原生标题栏**承载 | ✅ |
| **同步**入口 | ❌ 请回**主窗口** | ✅ |
| **设置**入口 | ❌ 请回**主窗口** | ✅ |

- **主窗口布局不变**：**宽屏 / 窄屏 / Web** 的布局与本次改动**无关**，一仍其旧。
- **不新增设置项**：本轮**没有**引入任何新的开关或偏好项。

> **已知限制**：独立窗口内**没有**同步 / 设置入口（请回**主窗口**操作）；把**同步状态并进模式行**
> 的增强**本轮未做**。

### 3.24 网页原件：保留原布局的内嵌网页（v0.16.0 / M16 / FR-83）

用「**全页快照**」剪藏后，笔记正文头部会出现一行：

```
[网页原件](sui://webclip/<sha256>)
```

- **预览模式**：这一行渲染为**内嵌网页**（固定高度、可滚动），原页的布局 / 颜色 / 对齐 / 表格 /
  图文混排按浏览器方式还原；右上角「全屏」可沉浸查看。
- **格式模式**：这一行是**原子卡片**——单击选中、双击全屏，不会露出 `sui://` 长串；
  在卡片后按退格 / 删除键**整块删除**（一次撤销即可恢复）。
- **原件是附件**：HTML 字节按 sha256 内容寻址存储、随笔记同步、按需拉取；**Markdown 正文仍是正本**，
  可继续搜索 / 编辑 / 版本历史。
- **安全**：WebView **禁用 JavaScript、禁止联网、拦截外部导航**；原件里的脚本与事件属性在保存前已剔除。
- **降级**：Windows 未安装 WebView2 Runtime、Linux、原件尚未同步或 HTML 超过 12 MiB 时，
  显示「整页截图 + 打开原件」卡片，不影响正文编辑。
- **模式边界**：只有「全页快照」产生原件；「智能提取正文」行为不变。扩展默认选「全页快照」。

> **已知限制**：跨域样式表 / CSS 背景图 / 依赖 JS 的动态内容可能未完整保留；原件保存的是**采集时刻**的 DOM。

### 3.25 笔记本折叠 / 搜索、收件箱回退与编辑焦点（v0.16.0 / M16 / FR-84\~FR-89）

- **笔记本折叠**：有子笔记本的节点左侧有 chevron，点击只折叠 / 展开该节点，不改变当前选中的笔记本。

- **关联笔记跨本跳转**：点关联链接会**先切到目标笔记本**再选中目标；目标在收件箱 / 归档时切到对应视图。

### 3.26 选择正文区域剪藏（v0.16.2 / M16 / FR-90）

首页、频道页、列表页的页头 / 导航 / 页脚 / 侧栏往往很多，自动提取可能把整页都带进来。
这时用**手动选择正文**：

1. 打开扩展浮层，点「**选择正文区域剪藏…**」（或页面右键 →「选择正文区域剪藏」）。
2. 鼠标移到正文容器（`<article>` / `<main>` / 内容 `<div>`）会高亮；点击选中，`Esc` 取消。
3. 扩展只保留 `body → 选中元素` 的**祖先链**与选中内容，页头 / 页脚 / 侧栏等兄弟节点被排除；
   `<head>` 里的样式与外部样式表保留，由服务端拉取并内联。
4. 笔记按「全页快照」处理（Markdown + 网页原件），但**不采集整页截图**——截图会把页头页脚又带回来。

> 建议选**包含正文的最大容器**；选得太小（例如只选一个段落）就只剪这一段。
> 旧剪藏（`v0.16.1` 之前）没有保留外部样式表，需要重新剪藏一次。

## 4. 多端同步

### 4.1 同步时机

- 客户端本地变更（新建 / 编辑 / 删除）**立即在本地库中记成「待上传」**——上行队列就是库里的
  状态本身，所以重启应用、甚至换了服务端，未上传的意图都不会丢；停止输入约 0.7 秒后自动推送。
- 服务端有变更时通过 **WebSocket** 通知各客户端，触发增量拉取。
- 另有 **30 秒周期兜底同步**：断网期间积压的改动、或 WS 断开时的变更，恢复网络后
  无需你再动一次手也会自动补上；空闲时几乎无网络开销。

### 4.2 冲突处理（无需用户干预）

当两个设备同时编辑同一篇笔记时：

1. 服务端以 `base_version` 判定冲突。
2. 后提交的一方收到冲突响应，本地自动**启发式合并**：
   - 标题：取较新的一方。
   - 正文：合并双方内容，冲突段落以标记分隔，**绝不丢字**。
3. 合并结果自动重发，最终各端一致。

### 4.3 离线使用

离线时一切功能正常（查看、编辑、搜索），改动都会记账在本机（状态显示「待上传」；若从未连过
服务端则是「仅本地」）；恢复网络后自动推送，服务端会以服务器时间线对齐合并。

附件有两点例外：

- **未缓存到本机的附件离线打不开**（卡片显示「未下载」），联网后点击即可下载。
- 离线时新添加的附件仍会成功挂到笔记上（卡片显示「待上传」），联网后自动补传。

### 4.4 同步状态怎么看

每篇笔记、每个笔记本的条目上都带一个**同步状态图标**，「哪些还没到云端」一眼可辨：

| 状态 | 图标 | 含义 |
|------|------|------|
| 已同步 | 淡色对勾 | 本机改动都已在云端，两边版本一致（视觉权重最低，不打扰你） |
| 待上传 | 向上箭头 | 本机有改动还没传上去，而云端**已经持有**这个条目 |
| 仅本地 | 云朵加斜杠 | 云端**从来没有**这个条目——只有这台设备上有 |
| 冲突 | 分叉箭头 | 云端改过、本机也改过，两边内容都要保留 |
| 同步失败 | 感叹号 | 最近一次上传 / 下载失败，会保留失败原因与时间 |

**把鼠标停在图标上**（手机窄屏长按）就能看到具体缘由，例如「仅本地：云端没有该实体（该笔记本只
存在于本机）」「同步失败：Connection refused（10-09 21:14）」。窄屏下图标收缩为一个小圆点，
颜色含义不变。

> 还没在「同步设置」里连上服务端时，本机条目一律显示为**仅本地**的弱化样式：此时「已同步」
> 没有意义，界面**不会**假装已同步。

### 4.5 单个重新同步与「全部重新同步」

- **单项重试**：某一条笔记 / 笔记本卡住时，用它的**「立即上传 / 重试」**——笔记列表的行尾菜单
  （或右键菜单）里就有这一项，笔记本节点菜单里也有同一项（已是冲突的项，入口显示为
  「查看冲突 / 合并」）。它**只影响这一项**，不动其它数据、也不打断你正在编辑的内容。
- **全部重新同步**：对**云端与本机的全部数据**做一次「**核对 → 补齐**」——云端没有的本机条目补传
  上去，云端更新的条目拉下来，两边都改过的走既有自动合并（**绝不丢字**）。入口有两处、**同一实现**：
  桌面端菜单「**同步 → 全部重新同步**」，以及「**同步设置**」对话框里的「全部重新同步」面板
  （未连接服务端时置灰）。过程可取消、可重复执行（幂等），并给出进度、**逐项结果与失败原因**；
  失败项可以单独重试，也可以「重试全部失败项」。
- **什么时候用**：换了电脑 / 重装客户端后数据对不上、怀疑有内容没同步、或从「仅本地」的提示中
  恢复时。
- 首轮核对会从云端拉一遍**完整数据（含正文）**，笔记很多时会慢一些；这是一次性的。

### 4.6 更换服务端 / 服务端重建后（换库提示）

客户端会记住「原来那份云端数据」的身份（云端实例标识）。当你**换了服务端地址、换了数据目录，
或服务端被重建 / 回滚**时，它会发现「云端已经不是原来那一份」，弹出标题为
「**云端数据已更换 / 重建**」的对话框，列出「本机记录」与「云端」两边的实例标识，
让你决定怎么办。**在你做出选择之前，客户端不会上传、也不会清空任何一端的数据**：

| 选项 | 会发生什么 |
|------|------------|
| **用本地数据补齐到云端** | 以本机数据为准补齐云端：本机独有的条目会上传到云端；云端独有的条目仍会拉下来 |
| **以云端为准（不补齐）** | 以云端数据为准：只把云端条目拉到本机；本机独有、云端没有的条目**不会被删除**，只降级为「仅本地」且**不再自动上传**（想上传就用单项「立即上传 / 重试」，或再跑一次核对） |
| **取消** | 什么都不做：两端数据都不动，之后还可以再选（对话框的默认焦点就落在「取消」上） |

> ⚠️ 「以云端为准」**不等于删数据**——本机独有的笔记 / 笔记本仍完整保留在本机，只是状态变成
> 「仅本地」，界面会一直提示你它们还没到云端。

## 5. 版本历史与恢复

### 5.1 查看历史

1. 打开一篇笔记，点击编辑区右上角「历史」图标。
2. 弹出「版本历史」面板：列出该笔记的所有修订（时间、来源设备）。桌面宽屏在右侧栏呈现，
   **手机等窄屏（Android / iOS）整页推入**，能力一致。
3. 点击任意版本，下方展示该版本的 Markdown 内容。
4. 看完后按返回键回到编辑页（先关闭历史面板，再按才退出编辑返回笔记列表）。

### 5.2 恢复历史版本

1. 在版本历史面板选中目标版本。
2. 点击「恢复此版本」，确认。
3. 恢复以**新修订**形式追加（不重写历史），当前内容变为所选版本内容，原历史完整保留。

> 说明：历史记录以服务端合并记录为准，所有端看到的历史一致；本地未同步的编辑在同步后
> 并入服务端时间线。

## 6. 数据导出

1. 打开笔记，点击编辑区右上角「导出」图标。
2. 弹窗预览完整 Markdown（含标题），点击「复制全部」。
3. 粘贴到任意 Markdown 编辑器 / 文件即可。
