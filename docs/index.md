- **已知限制**：
  - 搜索为 `title` / `content` 的 `LIKE` 子串匹配（FTS5 仅架构预留，未启用）
  - 编辑器为「格式 / 源码 / 预览」三态，Markdown 为正本，暂无富文本 WYSIWYG
  - Web 端附件缓存为进程内内存态（刷新后按需重下）
  - 首次「全部重新同步」会做一次**带正文的全量 pull**（核对用的精简清单为演进项），笔记很多时首轮较慢
  - 批量导入的去重以**本机**为范围（跨端重复导入会再产生一份）；GBK / GB18030 文本不支持；HTML 里的远端图片**不下载**（保持原 URL）；印象笔记官方 HTML 导出对**非图片附件**没有可用链接，只保留显示文本；导入**不写入**原创建 / 修改时间与标签
  - 字体**不随包分发**：可选字体取决于**本机已安装**的系统字体；Web 端因浏览器渲染器不提供宿主字体，仅支持「跟随系统」，故各端观感可能不同
  - 主题、字体与「笔记本默认字体」覆盖均为**本机偏好**，不随同步跨端一致
  - **剪贴板富文本粘贴只在 Windows 与 Android 支持**（Windows `CF_HTML` / Android `ClipData`）；macOS / Linux / Web 读不到剪贴板的 HTML 表示，`Ctrl+V` **回落为纯文本**（内容完整、只是没有格式），属**已知限制**
  - 「全页快照」正文里的**受限内嵌 HTML 块**是**正本的一部分**（版式保真用）：源码模式逐字可见可编辑、预览态按受限样式渲染、格式模式按**原子块**整块呈现与整块删除；`article` 模式与既有纯 Markdown 快照笔记**行为不变**（不迁移历史数据）
  - **整页截图**由扩展滚动拼接：页面上 `position: fixed` 的吸顶 / 悬浮元素会在**拼接接缝处重复出现**（可稳定复现，本轮不修）；超长页面超出截图体积 / 高度 / 耗时闸门时会**放弃截图**（不影响剪藏成功）
  - 格式模式下**手打** `**x**` / `~~x~~` / `==x==` 会落成**转义字面量**（语法不生效）——要生成结构请用
    **工具栏**或**源码模式**（这是 FR-78 转义口径的**必然结果**）；**笔记内查找不做正则、不跨行**，
    格式模式命中**结构区**时**跳过**并提示「已跳过 N 处结构区」
  - **关联笔记的显示文字是写入时的标题快照**，目标重命名后**不自动跟随**；`==~~文字~~==`（高亮包删除线）
    **反向嵌套保持现状**（两态一致，登记为**待决项**）

  - 内置服务端不终止 TLS：公网部署请用反向代理承载 HTTPS（见[部署指南](deployment.md)）
