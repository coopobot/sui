## 项目现状速览

- **版本**：`0.10.0`
- **里程碑**：M0–M10 全部完成（框架与基本功能 / 笔记本分组与标签同步 / 整理与格式化编辑 / 单用户服务化与安全加固 / 编辑器增强 / 全页快照与离线自持剪藏 / 桌面端界面布局优化 / 桌面端独立笔记窗口 / 编辑器编辑能力与附件体验增强 / **认证与笔记安全加固**：短时访问令牌 + 可撤销刷新令牌、HTTP 下的应用层**受保护通道**、**可单独加密的笔记本**）
- **测试**：服务端 22/22、note_core 130+/130+、flutter_app 70+/70+ 全绿；两个 Dart 包 `analyze` 零问题
- **已知限制**：
  - 搜索为 `title` / `content` 的 `LIKE` 子串匹配（FTS5 仅架构预留，未启用）
  - 编辑器为「格式 / 源码 / 预览」三态，Markdown 为正本，暂无富文本 WYSIWYG
  - Web 端附件缓存为进程内内存态（刷新后按需重下）
  - 鉴权为演示级（明文密码前缀比对、无 Token 过期、无内置 HTTPS、CORS 全放开），公网部署前必须加固
