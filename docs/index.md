## 项目现状速览

- **版本**：`0.12.0`
- **里程碑**：M0–M12 全部完成（**M3 与 M11 编号有意留空**，为让里程碑号与版本号对应）：框架与基本功能 / 笔记本分组与标签同步 / 整理与格式化编辑 / 单用户服务化与安全加固 / 编辑器增强 / 全页快照与离线自持剪藏 / 桌面端界面布局优化 / 桌面端独立笔记窗口 / 编辑器编辑能力与附件体验增强 / **认证与笔记安全加固**（短时访问令牌 + 可撤销刷新令牌、HTTP 下的应用层**受保护通道**、**可单独加密的笔记本**）/ 最新 **M12 = `v0.12.0`「逐项同步状态与云端核对补齐」**：笔记 / 笔记本（标签共用同一机制）各有**本地逐项同步状态**，可单项重试、可一键「全部重新同步」（核对 → 补齐），并能识别**云端实例身份变化**（换库 / 重建）后按提示自愈
- **测试**：服务端 `go test ./...` 全绿、`note_core` **329/329**、`flutter_app` **171/171** 全绿；两个 Dart 包 `analyze` 零问题
- **已知限制**：
  - 搜索为 `title` / `content` 的 `LIKE` 子串匹配（FTS5 仅架构预留，未启用）
  - 编辑器为「格式 / 源码 / 预览」三态，Markdown 为正本，暂无富文本 WYSIWYG
  - Web 端附件缓存为进程内内存态（刷新后按需重下）
  - 首次「全部重新同步」会做一次**带正文的全量 pull**（核对用的精简清单为演进项），笔记很多时首轮较慢
  - 内置服务端不终止 TLS：公网部署请用反向代理承载 HTTPS（见[部署指南](deployment.md)）
