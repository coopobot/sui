## 1. 整体概念

随手记 Sui 采用「**本地优先 + 自托管服务端**」架构：

- **本地优先**：你的所有笔记保存在设备本地（SQLite），不联网也能正常查看、编辑、搜索。
- **自托管**：同步服务端跑在你自己控制的机器上（家里的电脑、NAS 或云服务器），数据完全归你所有。
- **多端**：手机、平板、电脑、浏览器（Web）使用同一套笔记，通过服务端同步保持一致。

几个关键术语：

| 术语 | 含义 |
|------|------|
| 笔记本 | 笔记的分组容器，可嵌套（如「工作 / 项目A」） |
| 标签 | 跨笔记本的柔性分类，一篇笔记可打多个标签 |
| 收件箱 | 专门收纳网页剪藏产生的笔记，一键剪藏后统一整理 |
| 剪藏 | 通过浏览器扩展把网页保存为笔记（自动转为 Markdown） |
| Token | 访问你服务端的凭证，相当于密码 |
| 版本历史 | 一篇笔记的所有历史修订，可随时回滚 |

## 2. 部署服务端

### 2.1 环境要求

- 任何支持 Go 1.26 的平台（Linux / macOS / Windows / NAS）
- 无需数据库软件 —— SQLite 内嵌，数据就是一个文件目录

### 2.2 构建并启动

```bash
cd server
go build -o bin/sui-server ./cmd/sui-server
./bin/sui-server
```

启动后默认：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 监听地址 | `:8080` | 用环境变量 `SUI_ADDR` 覆盖，如 `SUI_ADDR=:9000` |
| 数据目录 | `./data` | 用环境变量 `SUI_DATA` 覆盖，如 `SUI_DATA=/var/lib/sui` |

数据目录包含：

```
data/
├── sui.db          # 所有笔记 / 修订 / 用户 / 元数据（SQLite 单文件）
└── blobs/          # 附件二进制（按 sha256 分片存储，自动去重）
```

> 备份 = 拷贝整个数据目录。停止服务后复制即可。

### 2.3 验证服务已启动

```bash
curl http://localhost:8080/healthz      # → ok
curl http://localhost:8080/api/v1/ping  # → {"ok":true}
```

### 2.4 公网 / 局域网访问（可选）

多端同步需要客户端能访问到服务端：

- **局域网**：直接使用机器 IP，如 `http://192.168.1.10:8080`（注意放行防火墙端口）。
- **公网**：推荐用 Nginx / Caddy 反代并启用 HTTPS，例如：

```nginx
# Caddy
sui.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

服务端已内置 CORS 支持与 WebSocket 升级，反代时保持 `Upgrade` 头即可。

## 3. 注册账号与 Token

服务端采用最简单的 Token 鉴权模型：**一个用户、一个 Token**。

### 3.1 注册（获取 Token）

```bash
curl -X POST http://localhost:8080/api/v1/register \
  -H "Content-Type: application/json" \
  -d '{"username":"me","password":"secret"}'
```

响应：

```json
{"ok":true,"token":"a1b2c3...","username":"me"}
```

记下 `token`，这是所有客户端和扩展访问服务端的凭证。

### 3.2 登录（重新获取 Token）

忘记 Token 或想更换时：

```bash
curl -X POST http://localhost:8080/api/v1/login \
  -H "Content-Type: application/json" \
  -d '{"username":"me","password":"secret"}'
```

> 说明：当前版本为演示级鉴权，密码以明文前缀存储于服务端数据库。生产部署前请务必修改 `server/internal/api` 与 `server/internal/store` 中的实现（哈希密码、限流、HTTPS）。详细见 [开发者文档](DEVELOPER.md#安全与生产化)。

## 4. 安装客户端

### 4.1 运行 Flutter 客户端

客户端默认连接 `http://127.0.0.1:8080`。

```bash
cd clients/flutter_app
flutter run -d windows   # Windows 桌面
flutter run -d linux     # Linux 桌面
flutter run -d chrome    # 浏览器（Web）
flutter run -d android   # Android 手机 / 平板（需连接设备）
```

### 4.2 客户端界面

桌面 / 平板宽屏下为**三栏布局**：

```
┌─────────────┬──────────────┬──────────────────────┐
│ 笔记本树     │ 笔记列表      │ 编辑区（Markdown 双轨） │
│ ├ 全部笔记   │ · 笔记 A     │                      │
│ ├ 收件箱     │ · 笔记 B     │  源码 ⇄ 预览切换       │
│ ├ 工作       │              │  历史 / 导出 / 删除    │
│ │ └ 项目A    │              │                      │
│ └ 生活       │              │                      │
│ 标签: #xxx   │              │                      │
└─────────────┴──────────────┴──────────────────────┘
```

手机窄屏自动切换为抽屉式导航，点击左上角菜单展开笔记本树。

## 5. 日常使用

### 5.1 新建笔记

1. 点击笔记本树右上角「＋」→ 选择笔记本（或留空放「全部笔记」）。
2. 输入标题与正文，正文使用 Markdown 语法。
3. 内容自动保存（无需手动点保存）。

### 5.2 Markdown 双轨编辑

- **编辑**：左侧编辑原始 Markdown 源码。
- **预览**：点击「预览」切换为渲染后的效果。
- 支持：标题 `#`、列表、链接、图片、粗斜体、引用、代码块、表格等常见语法。

### 5.3 管理笔记本与标签

- **新建笔记本**：笔记本树底部「＋ 新建笔记本」。
- **嵌套**：在笔记本上右键 / 长按 → 新建子笔记本。
- **标签**：编辑器中输入标签回车即可添加，点标签可在全局过滤。

### 5.4 搜索

顶部搜索框输入关键字，即时匹配**标题与正文**，全局范围（也可先选中某个笔记本再搜索）。

### 5.5 置顶 / 归档 / 删除

- **置顶**：列表项右上角图钉，置顶笔记排在最前。
- **删除**：编辑器右上角垃圾桶；删除为软删除（墓碑），多端同步后保持一致。

## 6. 网页剪藏扩展

### 6.1 安装（Chrome / Edge）

1. 打开浏览器扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 打开右上角「开发者模式」开关。
3. 点击「加载已解压的扩展程序」，选择项目中的 `extension/` 目录。
4. 工具栏出现「随手记 Sui」图标即安装成功。

### 6.2 配置服务端

1. 右键扩展图标 →「选项」。
2. 填写：
   - **服务端地址**：如 `http://192.168.1.10:8080`
   - **访问 Token**：注册账号时获得的 token
3. 点击保存，自动验证连接；显示「✓ 设置已保存」即可使用。

> 配置保存在浏览器 `storage.sync`，同一浏览器账号多台设备间自动同步。

### 6.3 使用剪藏

两种方式：

| 方式 | 操作 | 效果 |
|------|------|------|
| 一键剪藏 | 点击工具栏扩展图标 →「剪藏此页面」 | 保存当前整个网页 |
| 右键剪藏 | 在页面 / 选中文字 / 链接上右键 →「剪藏到随手记 Sui」 | 保存页面或所选内容 |

剪藏流程：

1. 扩展抓取页面完整 HTML 发送到服务端。
2. 服务端类 Readability 净化：剔除导航、广告、页脚等噪声，提取正文。
3. HTML 自动转换为 Markdown，正文开头附来源链接。
4. 以**网页 URL 为幂等键**：同一网页重复剪藏会更新同一篇笔记，不会产生重复。
5. 笔记自动进入客户端的「收件箱」，来源标记为剪藏。

> 提示：重复剪藏同一网页 = 更新原文，可在客户端收件箱查看历史版本找回旧内容。

## 7. 多端同步

### 7.1 同步时机

- 客户端本地变更（新建 / 编辑 / 删除）**立即入 Outbox**，联网后自动推送。
- 服务端有变更时通过 **WebSocket** 通知各客户端，触发增量拉取。

### 7.2 冲突处理（无需用户干预）

当两个设备同时编辑同一篇笔记时：

1. 服务端以 `base_version` 判定冲突。
2. 后提交的一方收到冲突响应，本地自动**启发式合并**：
   - 标题：取较新的一方。
   - 正文：合并双方内容，冲突段落以标记分隔，**绝不丢字**。
3. 合并结果自动重发，最终各端一致。

### 7.3 离线使用

离线时一切功能正常（查看、编辑、搜索），变更积压在 Outbox；恢复网络后自动推送，服务端会以服务器时间线对齐合并。

## 8. 版本历史与恢复

### 8.1 查看历史

1. 打开一篇笔记，点击编辑区右上角「历史」图标。
2. 右侧弹出「版本历史」面板：列出该笔记的所有修订（时间、来源设备）。
3. 点击任意版本，下方展示该版本的 Markdown 内容。

### 8.2 恢复历史版本

1. 在版本历史面板选中目标版本。
2. 点击「恢复此版本」，确认。
3. 恢复以**新修订**形式追加（不重写历史），当前内容变为所选版本内容，原历史完整保留。

> 说明：历史记录以服务端合并记录为准，所有端看到的历史一致；本地未同步的编辑在同步后并入服务端时间线。

## 9. 数据导出

1. 打开笔记，点击编辑区右上角「导出」图标。
2. 弹窗预览完整 Markdown（含标题），点击「复制全部」。
3. 粘贴到任意 Markdown 编辑器 / 文件即可。

## 10. 常见问题

**Q：客户端连不上服务端？**
A：确认服务端已启动、地址端口正确；跨设备时确认防火墙放行；Web 端跨域问题已由服务端 CORS 解决。

**Q：剪藏扩展提示「连接失败：HTTP 401」？**
A：Token 错误或已过期，重新注册 / 登录获取新 Token，更新扩展设置。

**Q：剪藏结果没有正文？**
A：部分网页（如纯 JS 渲染的单页应用）正文在脚本执行后生成，扩展抓取的是原始 HTML。可先选中网页文字再右键剪藏。

**Q：两个设备都改了同一篇笔记，会丢内容吗？**
A：不会。冲突自动合并，双方内容都会保留（冲突段落带标记分隔）。

**Q：如何备份？**
A：停止服务端后整体拷贝数据目录（`sui.db` + `blobs/`）。恢复时放回原路径重启即可。

**Q：忘记 Token 怎么办？**
A：调用登录接口用用户名密码重新获取 Token，然后更新各客户端 / 扩展设置。
